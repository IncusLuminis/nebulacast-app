# Spec — Star Labels Upgrade + Lightweight Enrichment (v1)

Цель этапа:
1) убрать внутренний `id` звезды из UI;
2) заменить его на байеровское обозначение (или имя собственное);
3) минимально обогатить sky-card данными из SIMBAD;
4) добавить компактный Aladin preview (200x200).

Без изменения архитектуры карты и без тяжёлых каталогов.

---

## 1. Scope (что делаем сейчас)

### 1.1. Tooltip (hover)
Показываем только:

- `display_name`
- `RA/Dec` (J2000, sexagesimal)
- `mag` (value + band, если есть)

Формат:

Deneb  
RA 20h41m25s  Dec +45°16′49″  
Mag 1.25 (V)

Правила:
- Если есть `proper` → показываем его.
- Иначе показываем `bayer + con`.
- Иначе `flam + con`.
- Иначе `HD` или `HIP`.
- Внутренний `id` не отображается.

---

## 2. Sky-card (STAR)

### 2.1. Header

Порядок строк:

1. Proper name (если есть)
2. Bayer designation (например, α Cyg)
3. Каталожные: HD / HIP (мелким шрифтом)

Пример:

Deneb  
α Cyg  
HD 197345 · HIP 102098

---

### 2.2. Основные поля (локальные из HYG)

Показываем:

- RA/Dec (J2000)
- Alt/Az (если есть observer context)
- Mag
- Spectral type (`spect`)
- Distance (если есть dist)
- Proper motion (опционально, компактно)

Без внешних запросов — карточка полностью работоспособна.

---

## 3. SIMBAD Enrichment (ленивый, по клику)

### 3.1. Архитектура

- SIMBAD дергается только:
  - при открытии карточки
  - либо при нажатии "More"
- Результат кэшируется (JSON cache, ключ = HIP или HD)
- Повторные запросы не выполняются

### 3.2. Что запрашиваем из SIMBAD

Минимальный набор:

- Spectral type (если отличается/уточняется)
- Object type (Star, Variable Star, High Proper Motion Star и т.п.)
- Variability type (если есть)
- Additional identifiers (опционально)

### 3.3. В карточке добавляем блок

Classification
• Spectral class: A2Ia
• Type: Variable Star
• Notes: High Proper Motion

Если данных нет — блок скрывается.

---

## 4. Aladin Preview (200x200)

### 4.1. Назначение
Небольшой визуальный контекст поля вокруг звезды.

### 4.2. Техническое решение

Вариант A (предпочтительный):
- Встроенный Aladin Lite iframe
- Размер 200x200 px
- FOV ~ 5–10 arcmin
- Survey: DSS2 / HiPS

Вариант B:
- Проксирование изображения через backend
- `/api/sky/preview?ra=...&dec=...&fov=...`
- Кэширование на сервере

### 4.3. Ограничения

- Загружать preview только при открытии карточки
- Не автозагружать для всех звёзд
- Не выполнять массовые запросы

### 4.4. UI поведение

- Если preview не загрузился → блок скрывается
- Картинка без heavy controls

---

## 5. Performance Constraints

1. Tooltip не должен вызывать никаких внешних API.
2. SIMBAD — максимум 1 запрос на звезду, с кэшем.
3. Aladin — грузится только при раскрытии карточки.
4. Никаких массовых фоновых enrichment-процессов.

---

## 6. Acceptance Criteria

- На карте больше не отображается внутренний `id`.
- Для звёзд до 4.5 mag отображаются Bayer или Proper name.
- Tooltip показывает только имя + координаты + mag.
- Sky-card работает полностью без SIMBAD.
- SIMBAD enrichment не блокирует рендер.
- Aladin preview не вызывает заметной деградации производительности.

---

## 7. Out of Scope (этот этап)

- Полная интеграция Gaia DR3
- Массовая классификация переменных
- Физические параметры (масса, радиус, светимость)
- Массовая загрузка изображений
