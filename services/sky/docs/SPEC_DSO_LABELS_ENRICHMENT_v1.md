# Spec — DSO Labels + Lightweight Enrichment (v1)

Цель этапа:
1) стандартизировать подписи DSO на карте (без внутренних id);
2) минимализировать tooltip;
3) расширять sky-card через SIMBAD (лениво, по клику);
4) добавить компактный Aladin preview (200x200).

Без тяжёлых каталогов и без массовых внешних запросов.

---

## 1. Scope (текущий этап)

### 1.1. Tooltip (hover)

Показываем только:

- `primary_designation`
- `RA/Dec` (J2000, sexagesimal)
- `Alt` (если есть observer context)
- `Mag` (если есть)

Формат:

NGC 7331  
RA 22h37m04s  Dec +34°24′56″  
Alt 42°  
Mag 9.5

Правила отображения названия:

Приоритет каталожного обозначения:
1. Messier (если есть)
2. NGC
3. IC
4. PGC / другое основное поле
5. fallback — любое доступное стандартное имя

Внутренний `id` никогда не показывается.

Tooltip не вызывает внешние API.

---

## 2. Sky-card (DSO)

### 2.1. Header

Порядок строк:

1. Primary designation (например, NGC 7331)
2. Secondary IDs (Messier / IC / PGC — если есть)
3. Тип объекта (если известен локально или из SIMBAD)

Пример:

NGC 7331  
Spiral Galaxy  
PGC 69327

---

### 2.2. Основные поля (локальные данные)

Показываем:

- RA/Dec (J2000)
- Alt/Az (если есть observer context)
- Mag
- Angular size (major × minor, если есть)
- Position angle (если есть)

Если размер или mag отсутствуют — соответствующие строки скрываются.

---

## 3. SIMBAD Enrichment (ленивый режим)

### 3.1. Архитектура

- Запрос выполняется только при открытии карточки или по кнопке "More"
- Кэширование по ключу (NGC/IC/M/PGC)
- Повторные запросы не выполняются

### 3.2. Минимальный набор данных из SIMBAD

Запрашиваем:

- Object type (Galaxy, Nebula, Cluster, PN, SNR и т.п.)
- Morphology (если galaxy)
- Angular size (если отсутствует локально)
- Redshift (если есть)
- Radial velocity (если есть)
- Основные альтернативные обозначения

### 3.3. Блок в карточке

Classification
• Type: Galaxy  
• Morphology: SA(s)b  
• Redshift: z = 0.0027  
• Radial velocity: 816 km/s

Поля показываются только при наличии данных.

---

## 4. Aladin Preview (200x200)

### 4.1. Назначение

Визуальный контекст области вокруг объекта.

### 4.2. Техническая реализация

Вариант A (предпочтительный):
- Встроенный Aladin Lite iframe
- Размер 200x200 px
- FOV ~ 10–20 arcmin (в зависимости от размера объекта)
- Survey: DSS2 / HiPS

Вариант B:
- Backend proxy
- `/api/sky/preview?ra=...&dec=...&fov=...`
- Серверное кэширование

### 4.3. Ограничения

- Preview загружается только при открытии карточки
- Нет массовых фоновых загрузок
- При ошибке загрузки блок скрывается

---

## 5. Performance Constraints

1. Tooltip полностью офлайн.
2. SIMBAD — максимум 1 запрос на объект (с кэшем).
3. Aladin загружается только при раскрытии карточки.
4. Никакой массовой фоновой индексации SIMBAD.

---

## 6. Acceptance Criteria

- На карте не отображаются внутренние id.
- Tooltip содержит только обозначение + координаты + alt + mag.
- Sky-card полностью работоспособна без SIMBAD.
- SIMBAD enrichment не блокирует UI.
- Aladin preview не вызывает заметной деградации производительности.

---

## 7. Out of Scope (этот этап)

- Полная интеграция NED / HyperLEDA
- Физические размеры и вычисления светимости
- Глубокая фотометрия
- Массовая автоматическая классификация DSO
